# MindMap

基于思维导图的项目管理桌面工具，使用 [MyGo](https://github.com/egoist/mygo) 原生 UI（Go 编写，GPU 绘制，无 WebView）开发，优先支持 macOS。

用一张思维导图管理项目的层级：模块、功能、实现细节、待优化点。节点可以写备注、打标签，也可以设为任务并安排日期。任务汇总到看板和日程视图中。

## 功能

- **导图文件管理**：左侧栏按文件夹分组显示导图（支持子文件夹，拖动导图到文件夹即可移动），顶部固定「★ 收藏」；右键可收藏、重命名、移动、在 Finder 中显示、移到废纸篓
- **节点样式**（右侧「样式」页）：形状、填充、边框、固定宽度，文字字号、加粗、斜体、删除线、下划线、对齐、颜色
- **标记**（右侧「标记」页）：标签色、优先级、任务进度、旗帜、星星、人像、符号，带图例；点击节点上的标记可切换
- **无限画布**：拖动中心节点移动整张图，滚轮或触控板平移，⌘+滚轮缩放，右下角有缩放和「回到中心」按钮
- **一个文件多个画布**：底部标签切换画布，+ 新建；双击标签重命名，右键可复制、移动、删除
- **结构**：每个画布可选思维导图、逻辑图、括号图（画布左上角或右侧「画布」页）
- **样式**（右侧「画布」页，参考 XMind）：配色方案（晨曦、经典、海洋、森林、暖阳、糖果、商务）、全局字体、分支线粗细、彩虹分支或单色分支
- **思维导图编辑**：中心节点居中，分支自动分布在左右两侧；长标题自动换行；分支配色、折叠/展开、拖动节点改变层级、右键菜单、撤销/重做
- **节点详情**（右侧面板）：标题、多行备注、图片、标签、任务属性
- **导出图片**：文件菜单「导出为图片…」（⌘⇧E）或画布右下角 ⤓，把当前画布的整张导图导出为 2 倍清晰度的 PNG
- **右侧面板可调宽度**：拖动面板左边的分隔线，宽度会记住
- **AI 回复按 Markdown 显示**：标题、列表、引用、代码、表格、粗体、斜体等
- **全局标签**：标签库在所有导图间共用，带颜色。节点面板里点标签即可打上或取消，输入新名称回车创建；节点右键菜单「标签」也能勾选。左侧「标签」区可「＋ 新建标签」，右键标签可重命名、改颜色、删除（重命名和删除会同步到文件夹里的所有导图）
- **图片**：选中节点按 ⌘V 粘贴截图或复制的图片文件，或把图片拖到节点上，或在节点详情里「添加图片…」；图片显示在标题上方，点击查看大图（Esc 关闭）。图片文件保存在导图旁的「名称.assets」文件夹里，重命名、移动导图时会一起移动
- **任务**：状态（想法 / 待做 / 进行中 / 完成）、优先级、开始和截止日期，逾期标红
- **大纲视图**：把画布当文字大纲编辑：回车新建一行，Tab / Shift+Tab 缩进，空行按退格删除，↑↓ 换行，和导图是同一份数据
- **演说模式**（右侧「演说」页或工具栏 ▶，⌘↩）：把画布自动生成幻灯片并全屏放映：标题页、每个有子主题的主题一页、带备注的主题一页；深色 / 浅色 / 彩色风格，列表或卡片布局，可逐条出现，← → 或空格翻页，Esc 退出
- **AI 助手**（工具栏「✦ AI」）：可选 Anthropic Claude（默认 Claude Opus 5.5，可选 Sonnet / Haiku / Fable）或 DeepSeek（默认 deepseek-flash，即 DeepSeek V4.1 Flash；可选 V4 Pro），在设置里切换服务商。对当前画布、选中节点或整个文件提问；让 AI 整理、拆分任务、补备注时，它会给出修改清单，你点「应用」后才写入导图，一步撤销。在设置中填写 API Key（保存在本机配置文件，仅当前用户可读），可选填代理接口地址
- **看板视图**：汇总文件中所有画布的任务，按状态分列，拖动卡片即可改变状态
- **日程视图**：按已逾期 / 今天 / 未来 7 天 / 以后 / 未安排日期分组
- **筛选与搜索**：左侧标签列表（标签多时可筛选）按标签筛选，或搜索标题、备注和标签。匹配的节点高亮，回车跳到下一个
- **记住每个导图的状态**：切换到别的导图再切回来，回到原来的画布、视图、位置和缩放、选中的节点，撤销记录也保留；重开应用后同样恢复（撤销记录除外）。这些保存在应用自己的配置目录（views.json），不写进导图文件
- **自动保存**：编辑停顿约 1 秒后自动写入文件，工具栏显示「已自动保存 时:分」，不需要手动保存
- **外部修改自动载入**：文件被其他程序（例如 AI 编码助手）修改后，自动载入新内容
- 浅色/深色主题跟随系统

## 下载安装（macOS）

在 [Releases](https://github.com/wuyunyoujiduo-jpg/mindmap/releases/latest) 下载 `.dmg`，打开后把 MindMap 拖进「应用程序」。应用没有经过苹果公证，第一次打开前在终端执行：

```sh
xattr -cr /Applications/MindMap.app
```

## 发布新版本

每次推送代码，GitHub Actions 只运行测试。macOS 应用只在两种情况下打包：发布版本时；或者在 Actions 页面选择 Build 工作流，点「Run workflow」手动运行（打好的包在运行记录里下载）。发布正式版本的步骤：

1. 修改 `mygo.json` 里的 `version`，比如改成 `0.2.0`，然后提交
2. 推送同名标签：`git tag v0.2.0 && git push origin v0.2.0`。也可以不推标签：在 Actions 页面手动运行 Build 工作流，勾选「发布 Release」

工作流会检查标签和版本号是否一致，打包后在 Releases 页面发布 `.dmg`。

## 从源码运行

需要 Go 1.27 或更高版本。如果本机 Go 版本更低，`go` 命令会自动下载所需的工具链。

```sh
go tool mygo dev      # 开发模式运行，修改代码后自动重载
go test ./...         # 运行测试（界面测试不打开窗口）
go tool mygo build    # 打包：macOS 生成 .app 和 .dmg，位于 build/
```

也可以直接用 `go run .` 运行。注意：在 macOS 上，系统通知等功能需要打包后的应用。

第一次启动时，程序会在 `~/Documents/MindMap` 创建文件夹，并放一份「使用指南」示例导图。点击左上角「打开…」可以换成其他文件夹，比如项目仓库中的某个目录。

| 操作 | 作用 |
|---|---|
| 拖动中心节点 | 移动整张图 |
| 滚轮 / 触控板双指滑动 | 平移 |
| ⌘ + 滚轮 | 以鼠标位置为中心缩放 |

| ⌘⇧0 | 回到中心 |

| ⌘⇧E | 导出为图片 |

## 快捷键（在导图画布上）

| 按键 | 作用 |
|---|---|
| Tab | 添加子节点 |
| Enter | 添加同级节点 |
| 双击 / F2 / 空格 | 编辑标题（Enter 确认，Esc 取消） |
| Delete / Backspace | 删除节点 |
| ← → | 远离中心节点：进入子节点（会展开折叠的节点）；朝向中心节点：回到父节点 |
| ↑ ↓ | 在同一侧的同级节点间移动 |
| ⌘↑ / ⌘↓ | 在同级中上移 / 下移 |
| ⌘/ | 折叠 / 展开 |
| ⌘Z / ⌘⇧Z | 撤销 / 重做 |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | 切换到思维导图 / 大纲 / 看板 / 日程 |
| ⌘N | 新建导图 |

拖动一个节点到另一个节点上，可以把它移到那个节点下面。

## 文件格式

每个导图保存为一个 `名称.mindmap.json` 文件，内容是缩进格式的 JSON，适合放进 git 管理和比较差异。一个文件包含一个或多个画布（`sheets`），每个画布是一棵节点树：

```json
{
  "version": 2,
  "sheets": [
    {
      "id": "5e6f7a8b9c0d",
      "title": "项目结构",
      "root": {
        "id": "a1b2c3d4e5f6",
        "title": "我的项目",
        "children": [
          {
            "id": "0f1e2d3c4b5a",
            "title": "列表加载慢",
            "note": "考虑分页或缓存。",
            "tags": ["性能"],
            "task": { "status": "todo", "priority": 3, "due": "2026-10-11T00:00:00+08:00" }
          }
        ]
      }
    }
  ]
}
```

- `status`：`idea` / `todo` / `doing` / `done`
- `priority`：0 无，1 低，2 中，3 高
- `collapsed`：为 `true` 时表示节点已折叠
- 旧版（`version: 1`，只有一个 `root`）的文件会自动当作只有一个画布的文件打开，保存时转成新格式

因为是纯文本，AI 编码助手也可以直接读写这个文件，比如完成任务后更新节点状态、补充实现备注。应用会自动载入这些外部修改。

## 代码结构

```
main.go            启动、窗口、菜单、系统对话框
app.go             应用状态与操作（打开/保存、编辑、撤销、导航）
view.go            整体布局、工具栏、侧栏
canvas.go          无限画布：节点、连线、平移缩放、键盘操作、拖放、画布标签
panel.go           右侧节点详情面板
tasks.go           看板与日程视图
export.go          导出图片：在内存中离屏绘制画布为 PNG
markdown.go        AI 回复的 Markdown 渲染
tags.go            全局标签库：新建、重命名、改色、删除，节点面板与右键菜单
welcome.go         首次启动的示例导图
config.go          记住上次的文件夹和导图
internal/model     数据模型、编辑操作、存储、撤销历史（不依赖 UI）
internal/layout    导图自动布局（不依赖 UI）
```

数据层和布局层都是纯 Go 包，有独立的单元测试。界面测试用 MyGo 的 `ui.Tester` 在内存中渲染、点击和输入。运行 `MINDMAP_SNAPSHOTS=<目录> go test .` 时，会把界面截图保存到该目录。
