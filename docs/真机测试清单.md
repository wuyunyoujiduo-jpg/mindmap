# 真机验证清单

自动化测试在内存里渲染界面，碰不到系统层面的功能。下面按优先级排，**先做前 10 项（约 10 分钟）**，有问题截图反馈即可。

## 必测（约 10 分钟）
1. [ ] 首次打开出现 3 步新手引导；点「跳过」后再打开不再出现
2. [ ] 在别的应用里按 ⌃⌥Space，弹出「快速记录」小窗；回车保存后窗口消失
3. [ ] 在别的应用里复制一段文字，按 ⌃⌥V，右上角出现「已收进资料库」通知
4. [ ] 截图（⌘⇧⌃4）后按 ⌃⌥V，资料库里出现这张图片
5. [ ] 设置 → 资料库：显示「✓ 正在使用内置模型」
6. [ ] 资料库里搜一个**意思相近但用词不同**的词，能找到对应资料
7. [ ] AI 助手的回答一段一段地出来（流式），不是等很久一次出来
8. [ ] 关掉应用再打开，同一张导图的 AI 对话还在
9. [ ] 菜单栏有 MindMap 图标，点开能看到今天到期的任务
10. [ ] 一张大导图（几百个节点）拖动、缩放流畅

## 选测
- [ ] 帮助 →「连接 AI 编程工具（MCP）」按说明接入 Claude Code，让它 search_library 搜一下资料、改一个任务状态
- [ ] 粘贴一个中文老网站链接（GBK 编码），正文不乱码；公众号文章读不到时可以手动粘贴正文
- [ ] 拖入 Word / PPT / PDF，能搜到里面的文字
- [ ] 设置 → 备份 →「每天自动备份到…」选一个文件夹，当天就生成 zip，解压后导图和 .library 都在
- [ ] 节点上的代码链接能用 VS Code / Cursor 打开到对应行
- [ ] 导出 XMind 后用 XMind 打开，结构、备注、任务都对
- [ ] 任务今天到期时收到系统通知
