# 真机验证清单

自动化测试在内存里渲染界面，碰不到系统层面的功能。下面按优先级排，**先做前 10 项（约 10 分钟）**，有问题截图反馈即可。快捷键写的是默认的，在 设置 → 通用 里改过的按改过的来。

## 必测（约 10 分钟）
1. [ ] 首次打开出现 3 步新手引导；点「跳过」后再打开不再出现
2. [ ] 在别的应用里按 ⌃⌥Space，弹出「快速记录」小窗；记下后窗口消失
3. [ ] 在别的应用里复制一段文字，按 ⌃⌥V，右上角出现「已存到收集」通知
4. [ ] 系统截图（⌘⇧⌃4）后按 ⌃⌥V，收集里出现这张图片
5. [ ] 第一次打开「收集」时提示下载语义检索插件（约 23MB）：点「下载」，有进度，装好后 设置 → 资料整理 显示「✓ 语义检索插件已安装」
6. [ ] 在收集里搜一个**意思相近但用词不同**的词，能找到对应资料
7. [ ] AI 助手的回答一段一段地出来（流式），不是等很久一次出来
8. [ ] 关掉应用再打开，同一张导图的 AI 对话还在
9. [ ] 菜单栏有 MyMind 图标，点开能看到今天到期的任务
10. [ ] 一张大导图（几百个节点）拖动、缩放流畅

## 选测
- [ ] 粘贴一个中文老网站链接（GBK 编码），正文不乱码；公众号文章读不到时可以手动粘贴正文
- [ ] 拖入 Word / PPT / PDF，能搜到里面的文字；拖入一段视频，卡片上是它的画面，指针移上去静音播放
- [ ] 设置 → 备份 →「每天自动备份到…」选一个文件夹，当天就生成 zip，解压后导图和 .library 都在
- [ ] 节点上的代码链接能用 VS Code / Cursor 打开到对应行
- [ ] 导出 XMind 后用 XMind 打开，结构、备注、任务都对
- [ ] 任务今天到期时收到系统通知；给一个任务设几分钟后的提醒时间，到点收到它自己的通知
- [ ] 「今天」的周视图里日期旁有农历和节气，法定节假日和调休的日子标着「休」「班」（要联网读到当年的安排）
- [ ] MyMind 自己的菜单（或菜单栏图标的菜单）开着的时候按截图的快捷键也有反应，截完菜单收起

## 截图（来自 OneShot）
- [ ] 第一次截图时系统请求「屏幕录制」权限；在 系统设置 › 隐私与安全性 › 录屏与系统录音 里允许 MyMind 后退出重开
- [ ] 在别的应用里按 ⌃⌘A（同 OneShot；先退出 OneShot，免得它占着）：框选、拖动、拉控制点，左上角显示像素尺寸
- [ ] 矩形、箭头、画笔、文字标注都能画，⌘Z 撤销
- [ ] 点工具条上的「存到收集」（或 ⇧↩）：收到「截图已存到收集」的通知，收集里多一张图片，焦点回到原来的应用
- [ ] 点 ✓（或 ↩、双击选区）：图片在剪贴板里；⌘S：弹出保存框，存好后有通知
- [ ] 在 MyMind 顶上一行点截图按钮：MyMind 窗口先让开，截完存到收集并选中这张图
- [ ] 多显示器时每块屏幕都能框选；别的应用全屏时也能截

## 同步到 GitHub
- [ ] 在 GitHub 新建一个空的私有仓库，创建只给它 Contents 读写权限的令牌
- [ ] 设置 → 同步：填仓库和令牌，「检查连接」显示「✓ 已连接私有仓库」，「立即同步」后仓库里出现导图和 .library
- [ ] 改一张导图后不用管它：五分钟一轮，下一轮过后左栏底部变成「已同步 时:分」，GitHub 上有一个新提交（这几分钟里改的都在这一个提交里）；不想等就点「立即同步」
- [ ] 第二台电脑填同一个仓库：导图和收集都下载下来；在一台上改，另一台在自己的下一轮（5 分钟内）自动更新
- [ ] 两台都改同一张导图后同步：自动合成一张；两边改了同一处的，弹窗逐处选用哪台的
- [ ] 旧版本留下的「GitHub 冲突」副本：同步后合进原导图，副本进废纸篓，可撤销
- [ ] **导图文件夹是一个软链接**（`ln -s 真正的文件夹 ~/Documents/MyMind`，再在应用里打开这个链接）：同步照常上传下载，仓库里和另一台电脑上的文件一个都没有少；再把一个导图文件的权限去掉（`chmod 000`）后同步，那个文件在仓库里还在，没有被当成删除（试完 `chmod 644` 改回来）
- [ ] 同样是软链接的文件夹，设置 → 备份 →「立即备份…」：zip 里有全部导图和 .library，不是一个空文件，里面没有 `.sync`

## 加密
- [ ] 设置 → 加密：设一个加密密码，记下恢复码。收集里记一条带密钥的内容（如 `sk-` 开头的一串）：卡片上是圆点，打开详情看它时问一次密码，之后一段时间不再问
- [ ] 同步后在 GitHub 上看这一条的文件：密钥是 `⟦mm1.…⟧` 这样的一串，不是原文
- [ ] 第二台电脑同步下来后，输入同一个密码能看到原文；用恢复码能改密码

## AI 编程工具
- [ ] 帮助 →「连接 AI 编程工具（MCP）」按说明接入 Claude Code，让它用 search_library 搜一下资料、改一个任务状态；它记下的出现在「今天」左栏的「AI 动态」里
- [ ] 点「装上」后新开一个 Claude Code 会话：开头自动读到项目简报；改了代码收工时它先记一笔
- [ ] **hook 和 agent 自己的 git 同时跑**：让 agent 改代码后马上 `git commit`（最好是一个大仓库，或连着做几次提交），会话结束时的 hook 不卡住、提交不报 `index.lock` 被占用；仓库在网络盘上或 git 很慢时，hook 最多等十几秒就安静结束，会话照常收尾

## 安装和更新
- [ ] 应用自己更新：装一个旧版本，菜单 MyMind →「检查更新…」，弹出更新说明，点「安装更新」后下载（差三个版本以内时下的是增量包，很快）、重启，版本号变了，Dock 里的图标还在原处
- [ ] **`update.sh` 在 Apple 芯片的 Mac 上**（没装过 MyMind 的机器最好）：按 README「安装」取到脚本运行，装上的是 `arm64` 的包，打开时系统不弹"无法验证开发者"
- [ ] **`update.sh` 在 Intel 的 Mac 上**：最新的版本只有 Apple 芯片的包时，它说「版本 x.y.z 没有这台 Mac（amd64）的安装包」并停下，原来的 App 没有动；`update.sh 0.33.1`（一个带 Intel 包的版本）装上的是 `amd64` 的包，能打开
- [ ] `update.sh -f` 重装时，正在运行的 MyMind 先自己退出，装完重新打开；下载或复制到一半按 ⌃C，原来的 App 还在
