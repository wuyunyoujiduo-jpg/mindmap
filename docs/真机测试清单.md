# 真机测试清单

自动化测试在内存里渲染界面，碰不到系统层面的功能。下面这些需要在 Mac 上手动过一遍，有问题截图反馈即可。

## 系统集成
- [ ] 在别的应用里按 ⌃⌥Space，弹出「快速记录」小窗口；回车保存后窗口消失，内容进了收件箱 / 资料库
- [ ] 在别的应用里复制一段文字，按 ⌃⌥V，右上角出现「已收进资料库」通知
- [ ] 截图（⌘⇧⌃4）后按 ⌃⌥V，资料库里出现这张图片
- [ ] 在 Finder 里复制一个 PDF，按 ⌃⌥V，资料库里出现这个文件，详情里有「文件内容」
- [ ] 同一个链接再收藏一次，通知显示「已经收藏过」
- [ ] 菜单栏图标：显示今天到期任务数；菜单里有快速记录、收藏剪贴板、资料库、任务列表
- [ ] 设置里改两个全局快捷键，改完立即生效
- [ ] 任务今天到期时，收到系统通知（每天一次）

## 资料库
- [ ] 粘贴一个普通网页链接：自动读出标题和正文，AI 加上说明、摘要、分类、标签
- [ ] 粘贴一个中文 GBK 网页（老的论坛 / 门户新闻）：正文不乱码
- [ ] 公众号文章读不到正文时，在「网页正文」框里手动粘贴，之后能搜到
- [ ] 拖入 Word / PPT / PDF：能搜到里面的文字
- [ ] 设置里配好向量模型（推荐 Ollama + bge-m3），「保存并测试」显示连接成功；用意思相近、用词不同的话能搜到资料
- [ ] 打开一条资料，底部「相关资料」合理
- [ ] 「回顾」→「AI 回顾最近 7 天」生成归纳；「把最近 7 天的资料生成导图」生成新导图，节点能点回资料

## AI
- [ ] AI 回复一个字一个字地出来（Claude 和 DeepSeek 各试一次）
- [ ] 在导图里问「我之前存过关于 xx 的资料吗」，它会检索资料库并注明依据
- [ ] 关掉应用再打开，同一张导图的 AI 对话还在；⋯ →「历史对话」能切回以前的对话
- [ ] 节点详情里「链接到资料…」能挑资料，节点上的 📚 链接能打开资料

## 其他
- [ ] 帮助 →「连接 AI 编程工具（MCP）」按说明接入 Claude Code，让它 search_library 搜一下资料
- [ ] 设置 →「每天自动备份到…」选一个文件夹，当天就生成一个 zip，解压后导图和 .library 都在
- [ ] VS Code / Cursor 打开节点上的代码链接，跳到对应行
- [ ] 导出 XMind 后用 XMind 打开，结构、备注、任务都对
